# Mini-C: опис мови та граматика

Mini-C — підмножина мови C. Кожна коректна програма Mini-C є також
коректною програмою на C, тому її можна скомпілювати `gcc` і порівняти
результат з нашим інтерпретатором та згенерованим Python-кодом.

## 1. Можливості мови

| Категорія        | Що підтримується                                              |
|------------------|---------------------------------------------------------------|
| Типи             | `int`, `double`, `void` (тільки як тип результату функції)    |
| Оголошення       | глобальні та локальні змінні, кілька в рядку, з ініціалізацією: `int a = 0, b = 1, t;` |
| Функції          | параметри, `return`, рекурсія, точка входу `main`             |
| Інструкції       | блок `{ }`, `if` / `if-else`, `while`, `for` (з оголошенням у заголовку), `break`, `continue`, `return`, вираз з `;`, порожня `;` |
| Оператори        | `=  +=  -=  *=  /=  %=`, `\|\|  &&  !`, `==  !=  <  >  <=  >=`, `+  -  *  /  %`, унарний `-`, `++` і `--` (префіксні та постфіксні) |
| Вбудовані функції| `printf("формат", ...)` зі специфікаторами `%d`, `%f`, `%.Nf`, `%%`, `\n` |
| Інше             | коментарі `//` і `/* */`; рядки `#include ...` ігноруються лексером |

Не підтримуються (свідоме спрощення): масиви, вказівники, структури,
`char`, приведення типів, тернарний оператор, `switch`, `do-while`.

## 2. Лексика (токени)

| Токен        | Приклад / регулярний вираз                         |
|--------------|----------------------------------------------------|
| ключові слова| `int double void if else while for return break continue` |
| `ID`         | `[A-Za-z_][A-Za-z0-9_]*`                            |
| `INT_LIT`    | `[0-9]+`                                            |
| `FLOAT_LIT`  | `[0-9]+\.[0-9]*` , `\.[0-9]+` (з можливим експонентом `e±N`) |
| `STRING`     | `"..."` з escape-послідовностями `\n \t \" \\`     |
| складені оператори | `== != <= >= && \|\| ++ -- += -= *= /= %=`   |
| однолітерні  | `+ - * / % < > = ! ( ) { } , ;`                      |

Пробіли, табуляції, переведення рядків, коментарі та рядки `#...`
пропускаються.

## 3. Граматика (BNF, у формі для Bison)

Термінали записано ВЕЛИКИМИ літерами або в лапках, ε — порожній ланцюжок.
Списки задано **лівою рекурсією** — для LALR-аналізатора це ефективніше
(стек не росте зі збільшенням довжини списку).

```
program       : external_list

external_list : external
              | external_list external

external      : func_def
              | var_decl

func_def      : type ID '(' params_opt ')' block

type          : INT | DOUBLE | VOID

params_opt    : ε
              | param_list

param_list    : param
              | param_list ',' param

param         : type ID

var_decl      : type init_list ';'

init_list     : init
              | init_list ',' init

init          : ID
              | ID '=' expr

block         : '{' item_list_opt '}'

item_list_opt : ε
              | item_list

item_list     : item
              | item_list item

item          : var_decl
              | stmt

stmt          : block
              | expr ';'
              | ';'
              | IF '(' expr ')' stmt
              | IF '(' expr ')' stmt ELSE stmt
              | WHILE '(' expr ')' stmt
              | FOR '(' for_init ';' expr_opt ';' expr_opt ')' stmt
              | RETURN expr_opt ';'
              | BREAK ';'
              | CONTINUE ';'

for_init      : expr_opt
              | type init_list

expr_opt      : ε
              | expr

expr          : ID '=' expr
              | ID ADD_ASSIGN expr          /* += */
              | ID SUB_ASSIGN expr          /* -= */
              | ID MUL_ASSIGN expr          /* *= */
              | ID DIV_ASSIGN expr          /* /= */
              | ID MOD_ASSIGN expr          /* %= */
              | expr OR  expr               /* || */
              | expr AND expr               /* && */
              | expr EQ  expr               /* == */
              | expr NE  expr               /* != */
              | expr '<' expr
              | expr '>' expr
              | expr LE  expr               /* <= */
              | expr GE  expr               /* >= */
              | expr '+' expr
              | expr '-' expr
              | expr '*' expr
              | expr '/' expr
              | expr '%' expr
              | '-' expr                    /* унарний мінус */
              | '!' expr
              | INC ID                      /* ++x */
              | DEC ID                      /* --x */
              | ID INC                      /* x++ */
              | ID DEC                      /* x-- */
              | ID '(' args_opt ')'         /* виклик функції */
              | '(' expr ')'
              | ID
              | INT_LIT
              | FLOAT_LIT
              | STRING

args_opt      : ε
              | arg_list

arg_list      : expr
              | arg_list ',' expr
```

## 4. Неоднозначність і як її знімаємо

Правила для `expr` навмисно записані **неоднозначно** (`expr : expr '+' expr`):
вираз `2 + 3 * 4` можна розібрати двома способами. Замість того щоб
переписувати граматику на багато рівнів (`additive`, `multiplicative`, ...),
ми задаємо Bison **пріоритети й асоціативність** операторів. Тоді
shift/reduce-конфлікти, які виникають у LALR-таблиці, розв'язуються
автоматично і правильно.

Пріоритети (від найнижчого до найвищого):

| Рівень | Оператори                       | Асоціативність |
|--------|---------------------------------|----------------|
| 1      | `=  +=  -=  *=  /=  %=`         | права          |
| 2      | `\|\|`                          | ліва           |
| 3      | `&&`                            | ліва           |
| 4      | `==  !=`                        | ліва           |
| 5      | `<  >  <=  >=`                  | ліва           |
| 6      | `+  -`                          | ліва           |
| 7      | `*  /  %`                       | ліва           |
| 8      | `!`, унарний `-`                | права          |

Друга відома неоднозначність — **«висячий else»** (dangling else):

```c
if (a) if (b) x = 1; else x = 2;
```

`else` можна приєднати і до зовнішнього, і до внутрішнього `if`.
Це класичний shift/reduce-конфлікт. За стандартом C `else` належить
**найближчому** `if`, що відповідає дії **shift**. Ми зробимо це явно
через `%nonassoc LOWER_THAN_ELSE` / `%nonassoc ELSE` і `%prec`, щоб Bison
не видавав попередження.

## 5. Семантичні правила (перевіряються після розбору)

- змінна має бути оголошена до використання (з урахуванням областей видимості);
- повторне оголошення в тій самій області — помилка;
- функція має бути оголошена, кількість аргументів має збігатися з кількістю параметрів;
- має існувати функція `main`;
- `break` / `continue` — тільки всередині циклу;
- `int` + `double` → `double` (неявне перетворення, як у C);
  `int / int` — цілочисельне ділення з відкиданням дробової частини до нуля
  (`-7 / 2 == -3`, а не `-4`, як у Python!).
